HP-mu via provider Indonesiaputus ✗
Cirinya khas sapuan daftar blokir provider: tadi siang normal → tiba-tiba mati, ganti sinyal & hapus cache tak mempan. Subdomain vercel.app memang sering ikut tersapu blokir massal di Indonesia.
OBAT 3 MENIT — GANTI DNS HP (lakukan sekarang)
1. Buka Setelan HP → cari di kolom pencarian setelan: "DNS Pribadi" (atau: Jaringan & internet → DNS Pribadi)
2. Pilih "Nama host penyedia DNS" → ketik persis: dns.google → Simpan
3. Matikan data seluler/Wi-Fi → nyalakan lagi (wajib, biar DNS segar)
4. Buka lagi web papan → harus normal → tarik-ke-bawah sekali (pull-to-refresh)
Kalau setelan "DNS Pribadi" tidak ketemu: pasang aplikasi gratis 1.1.1.1 + WARP (Cloudflare) → buka → tekan tombol besar CONNECT → balik ke Chrome → buka webmu.
OBAT PERMANEN (setelah papan normal lagi)
Pakai domain sendiri (contoh: papan.petanidollar.com) — bukan vercel.app, jadi tak bisa tersapu blokir massal. Cukup beli domain (murah) → Vercel → Domains → Add → ikuti 2 setelan yang Vercel tunjukkan. Kutanuntun klik-demi-klik saat kamu siap.
