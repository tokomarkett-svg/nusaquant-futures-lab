LANGKAH 1 · BUAT LAYANAN WEB DI RAILWAY (±6 menit)
1. Railway → proyekmu → kanan-atas + New → GitHub Repo → pilih nusaquant-futures-lab (repo yang sama dengan worker). Jangan deploy dulu — set dulu langkah 2–3.
2. Klik layanan baru itu → Settings → cari Build Command → Override → isi:
npm install --no-audit --no-fund && npm run build
3. Masih di Settings → Custom Start Command → isi:
npm run start
4. Tab Variables → tambah 4 variabel dari Langkah 0 (nama & nilai persis).
5. Settings → Networking → Generate Domain → Simpan → catat alamat barumu: web-production-xxxx.up.railway.app
6. Tunggu Deploy Success (±4 menit) → buka alamat baru → badge hijau FUTURES + kartu 🎯 = PINDAH BERES ✓
