Panduan TeleGram — klik per klik 📱
Semua langkah 0–11 terjadi DI DALAM aplikasi Telegram di HP-mu. Baru langkah 12 pindah ke Chrome (Railway).
Telegram = aplikasi chat (ikon pesawat kertas biru). Total waktu ±10 menit.
Dua kata yang muncul terus:
TOKEN = kunci bot (dari BotFather) — jangan kirim ke siapa pun.
CHAT ID = alamat tujuan pesan (angka dari userinfobot).
BAGIAN 1 · DI APLIKASI TELEGRAM
0
Buka aplikasi TELEGRAM
Telegram itu aplikasi CHAT (ikonnya pesawat kertas biru). Bukan Binance. Bukan Railway. Kalau belum ada: buka Play Store → cari «Telegram» → Install → daftar dengan nomor HP.
YANG KAMU LIHAT DI LAYAR
Kamu ada di daftar chat (banyak nama orang)
Di atas ada tulisan «Telegram» dan ikon 🔍
1
Ketuk ikon 🔍 (kaca pembesar) di atas
Ikon ini ada di pojok kanan atas daftar chat.
YANG KAMU LIHAT DI LAYAR
Muncul kolom pencarian kosong
Keyboard muncul di bawah
2
Ketik: BotFather
Ketik huruf apa saja, Telegram cari sendiri.
YANG KAMU LIHAT DI LAYAR
Muncul hasil: «BotFather ✔» (centang biru)
JANGAN pilih yang tanpa centang biru
3
Ketuk «BotFather» → ketuk tombol START / MULAI
Tombol biru besar di bawah layar.
YANG KAMU LIHAT DI LAYAR
Masuk ke chat BotFather
Muncul daftar perintah: /newbot, /help, dsb.
4
Kirim pesan: /newbot
Ketik /newbot di kolom chat → tekan tombol kirim (panah biru).
YANG KAMU LIHAT DI LAYAR
BotFather menjawab: «Alright, a new bot. How are we going to call it?»
Artinya: «nama bot-nya mau apa?»
5
Balas nama bot: NusaQuant Alert
Ini cuma nama tampilan, bebas.
YANG KAMU LIHAT DI LAYAR
BotFather bertanya lagi: «Good. Now let's choose a username…»
Artinya: «sekarang pilih username»
6
Balas username, WAJIB akhiran «bot»
Contoh: nusaquant_bri_bot (kalau ditolak, tambah angka: nusaquant_bri_bot2)
YANG KAMU LIHAT DI LAYAR
BotFather menjawab: «Done! … Use this token to access the HTTP API:»
Ada tulisan panjang: 1234567890:AAH... ← ITU TOKEN
7
COPY token-nya → simpan dulu di Catatan HP
Tekan lama tulisan 1234567890:AAH... → pilih Copy → buka Catatan HP → paste → simpan. (Token = kunci bot. Jangan kirim ke siapa pun.)
YANG KAMU LIHAT DI LAYAR
Di pesan BotFather ada juga link: t.me/nusaquant_bri_bot
8
Ketuk LINK t.me/namabot kamu
Link biru di pesan BotFather → Telegram membuka chat bot barumu.
YANG KAMU LIHAT DI LAYAR
Muncul layar kosong bertuliskan bot-mu
Di bawah ada tombol biru besar: START
9
Ketuk START → lalu TIDAK ADA balasan. Itu NORMAL.
Yang penting pesan «/start» sudah terkirim (muncul di sisi kanan).
YANG KAMU LIHAT DI LAYAR
Chat bot masih kosong — bot kita belum dipasangi balasan
Jangan tunggu jawaban, lanjut saja
10
Balik ke 🔍 → ketik: userinfobot
Lagi-lagi lewat kaca pembesar di daftar chat.
YANG KAMU LIHAT DI LAYAR
Muncul hasil «@userinfobot» → ketuk → ketuk START
11
@userinfobot membalas: «Id: 123456789» → COPY angkanya
Tekan lama angka itu → Copy → simpan di Catatan HP.
YANG KAMU LIHAT DI LAYAR
Itu «chat id» = ALAMAT tujuan pesan
Simpan bareng token tadi
BAGIAN 2 · DI CHROME (RAILWAY)
12. Tempel ke Railway → Variables
Buka Chrome → railway.com → project → service @nusaquant/worker → tab Variables → New Variable (3x):
TELEGRAM_BOT_TOKEN = (token dari langkah 7)
TELEGRAM_CHAT_ID   = (angka dari langkah 11)
RUN_ALERTS        = true
Tekan Save → tunggu 1–2 menit → HP-mu harus bunyi:
«✅ NusaQuant alert aktif» ← itu tanda SEMUA BENAR.
Kalau tidak masuk dalam 5 menit: buka Railway → Logs → cari tulisan «gagal kirim pesan sapa» → screenshot → kirim ke aku.
